## 🚀 اجرا

### روش ۱ — دابل‌کلیک (ساده‌ترین)

فایل `index.html` را در مرورگر باز کنید. تمام.

### روش ۲ — سرور محلی

```bash
# Python
python -m http.server 8080

# یا Node
npx serve .
```

سپس `http://localhost:8080` را باز کنید.

> 💡 نیازی به `npm install` یا build نیست — `bundle.js` از قبل آماده است.

    ├── patterns.js         # تحلیل الگوی خطا

## 🎯 مسیر آموزشی (هر زبان ۳۰ مرحله)

```
۱–۴    ردیف خانه (Home Row)
۵      کلمات ردیف خانه
۶–۸    ردیف بالا + ترکیب
۹–۱۰   ردیف پایین + هر سه ردیف
۱۱     کلمات پرتکرار
۱۲–۱۳  اعداد و علائم
۱۴–۱۶  جمله، پاراگراف، تسلط
۱۷–۲۱  تمرین متمرکز حروف
۲۲–۲۵  اعداد در جمله، نگارشی، پاراگراف
۲۶–۲۸  سرعت، دقت، ترکیب کامل
۲۹     ضرب‌المثل (فارسی)
۳۰     استادی نهایی ⭐
```

هر مرحله **آستانه سرعت و دقت** دارد. تا قبول نشدن، مرحله بعد قفل است.

## ⌨️ شورتکات‌ها

| کلید | عملکرد |
|------|--------|
| `Esc` | خروج از جلسه |
| `R` | تکرار جلسه (پس از پایان) |
| `Backspace` | حذف کاراکتر قبلی |
| `Enter` | سطر جدید (در متن چندخطی) |
| `Space` | فاصله (نیم‌فاصله خودکار حذف می‌شود) |

## 📦 بسته‌بندی به اپ دسکتاپ

پروژه کاملاً client-side است و برای Electron / Tauri آماده است:

app.whenReady().then(() => {
  const win = new BrowserWindow({ width: 1200, height: 800 });
  win.loadFile("index.html");
});
